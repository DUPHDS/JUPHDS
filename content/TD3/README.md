# TD3 : Functions

**Exercise 1 :**

Write a function maximum() that takes a list of numbers as an argument and returns the
maximum of this list of numbers.

**Exercise 2 :**

Write a function that takes a string and a file name as arguments. This function will write the
string to a file named with the name given as argument.

**Exercise 3 :**

Write a function that return mentions to students, if the grade is :
- Less than 10: Bad
- Between 10 and 12: Fair
- Between 12 and 14: Good
- Between 14 and 16: Very good
- Over 16: Congratulations.

1. First, create the mention() function, which takes a note as argument and returns the
associated mention.
2. Finally, create a function that takes a dictionary of students' names with their associated
grades and returns a dictionary of students' names with their associated grades.
3. What result do you get for {"Luna":16, "Georges":2, "Nicolas":11, "Jean":12}?

**Exercise 4 :**

Write a function called justOne() that removes duplicates from a list, leaving only one copy of each
item. Items can be numbers or strings.

**Exercise 5 :**

Write a checkType() function which checks that the list given as an argument only contains items of
the same type and returns True or False as appropriate.

**Exercise 6 :**

Write a magicReplace() function that takes a file path and a character as arguments. This
function will open the file and retrieve its contents. Then the character will be removed from
the content and a new file named "name_file]_magicReplace.txt" will be created with the
new content.

**Exercise 7 :**

1. Write a caculate() function which, when run, asks the user to enter two numbers and
asks him to choose between adding or subtracting these two numbers. The function
will only stop if the user wants to stop, as it can calculate several times from two
numbers. And each calculation result will be stored in a list returned at the end.
2. What is the list obtained if I first add 3 and 4, then subtract 9 and 15, then subtract 7
and 3 and finally add 1 and 76?

**Exercise 8 :**

many as he likes.
