# TD2 : Fichiers

**Exercice 1 :**
    1. Écrivez un fichier nommé « Hello.txt ».
    2. Ajoutez les informations suivantes, en utilisant un saut de ligne entre chaque information :
        a. Votre nom
        b. Votre âge
        c. Votre ville de naissance
    3. Fermez le fichier.
    4. Affichez chaque ligne du fichier « Hello.txt ».


**Exercice 2 :**


Le fichier « heart.csv » présente les informations cardiaques de plusieurs patients Kaggle et est disponible à l'adresse suivante : https://www.kaggle.com/ronitf/heart-disease-uci . L'objectif de cet exercice est de synthétiser les données. 


    1. Parcourez le document et comptez le nombre d'hommes et de femmes (« 0 » pour les femmes et « 1 » pour les hommes dans le document).
    2. La troisième colonne, « cp », indique le type de douleur thoracique ressentie par le patient. Pour chaque sexe, calculez le pourcentage de chaque type de douleur.
